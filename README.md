# FORGE ATHLETICS — Premium Fitness Club & Training Studio

https://forge-athletics-club.surge.sh/

> *"Build strength. Build yourself."*

A modern, production-grade website for **FORGE ATHLETICS**, a fictional premium athletic facility & training studio located in Toronto, ON. Designed with a bold editorial aesthetic, high-contrast dark palette, and thoughtful human-centric fitness programming.

🌐 **Live Demo**: [https://forge-athletics-club.surge.sh](https://forge-athletics-club.surge.sh)

---

## ⚡ Features

- **Editorial Athletic Aesthetic**: Deep charcoal (`#0B0C0E`), warm white typography, stone neutrals, and forged copper/amber accents (`#E58A2B`).
- **Typography**: Google Fonts `Syne` for editorial headers paired with `Plus Jakarta Sans` for clean, legible body copy.
- **15 Complete Views & Modal Workflows**:
  - **Home**: Full-screen Hero, Key Trust Stats, 5-Pillar About, Programs preview, 8-Week Beginner Blueprint timeline, 1-on-1 Personal Training breakdown, Coaches preview, interactive Class Schedule preview, Facilities showcase, Member Journey timeline, Community testimonials, interactive Progress Tracking demo widget, Journal preview, FAQ, and Conversion section.
  - **About**: FORGE origin story, 18,000 sq ft facility specs, HEPA air filtration standards, and coaching principles.
  - **Programs & Curriculum Modal**: 6 training disciplines with category filtering, week-by-week syllabus roadmaps, and direct consultation booking.
  - **Trainers & Profile Modal**: 6 fictional coaches (*Marcus Reed, Sophie Carter, Ethan Cole, Maya Brooks, Daniel Hayes, Olivia Grant*) with credentials (CSCS, SFG, NASM, FRC), philosophy pull-quotes, and direct booking.
  - **Class Schedule & Class Modal**: Full weekly matrix (Mon–Sun) with live filtering by Day, Modality, and Coach, spot availability indicators, and reservation confirmation toasts.
  - **Membership & Comparison Matrix**: Monthly vs. Annual toggle (-20% discount), Starter ($89/mo), Plus ($149/mo), and Elite ($229/mo) plans, plus a 12-row feature comparison table.
  - **Facilities & Equipment**: Visual tour of 8 training zones and comprehensive equipment inventory specifications.
  - **Fitness Journal & Article Reader**: 6 editorial articles with reading times, category tags, pull-quotes, and key takeaways.
  - **FAQ**: Searchable, categorized accordion.
  - **Contact & Location**: Inquiry form, studio address (*123 Athletic Avenue, Toronto, ON*), operating hours, directions, and parking details.
  - **Consultation / Visit Booking Flow**: 2-Step interactive modal (Goal selection & experience level $\rightarrow$ Date/time slot & contact details $\rightarrow$ Visual confirmation summary).
- **Responsive & Accessible**: Optimized for mobile, tablet, desktop, and large displays with sticky navigation and mobile quick-action bar.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or newer)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/pranavsahtih2104/Gym-Demo.git

# Navigate to the project directory
cd Gym-Demo

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at `http://localhost:3000/`.

### Production Build
```bash
npm run build
npm run preview
```
